# BibleFit 개인정보 처리방침

시행일: 2026년 7월 25일

BibleFit은 하루 한 구절 말씀, 묵상 타이머, 로컬 알림, 말씀 저장 기능을 제공하는 local-first 모바일 앱입니다.

## 수집하는 개인정보

BibleFit은 사용자의 개인정보를 수집하거나 외부 서버로 전송하지 않습니다.

- 회원가입을 제공하지 않습니다.
- 이름, 이메일, 전화번호, 위치 정보, 연락처, 사진, 마이크 입력을 수집하지 않습니다.
- 광고 SDK와 분석 SDK를 사용하지 않습니다.
- 생성형 AI API 또는 외부 해석 API를 호출하지 않습니다.

## 기기 안에 저장되는 정보

다음 정보는 앱 기능 제공을 위해 사용자의 기기 내부 SQLite 데이터베이스에만 저장됩니다.

- 저장한 말씀
- 묵상 완료일과 묵상 시간
- 스트릭 기록
- 알림 시간과 알림 사용 여부

이 정보는 개발자 서버로 전송되지 않으며, 앱을 삭제하면 함께 삭제됩니다.

## 알림 권한

BibleFit은 사용자가 매일 알림을 설정할 때 기기의 알림 권한을 요청할 수 있습니다. 알림은 기기에서 예약되는 로컬 알림이며, 알림 설정 정보는 기기 내부에만 저장됩니다.

## 배경음악

묵상 화면의 배경음악은 앱에 포함된 로컬 오디오 파일을 재생합니다. 녹음 기능을 제공하지 않으며 마이크 권한을 사용하지 않습니다.

## 성경 본문 출처

BibleFit MVP의 성경 본문은 eBible.org에서 공개 도메인으로 배포하는 Korean Bible 1910 자료를 기반으로 합니다. 앱 안에서는 사용자에게 익숙한 표시를 위해 `한글성경`으로 표기합니다.

## 제3자 제공

BibleFit은 사용자의 개인정보를 제3자에게 판매, 공유, 제공하지 않습니다.

## 데이터 삭제

BibleFit은 계정 기능을 제공하지 않습니다. 사용자는 앱을 삭제하여 기기 안에 저장된 BibleFit 데이터를 삭제할 수 있습니다.
